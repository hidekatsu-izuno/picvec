# 精度を維持した性能改善（2026-09-13）

変更前のコミットは `725a082`。画素数、フィット候補、誤差しきい値、統合の採用順、RGBAと4倍描画での検証条件は維持した。

- 共有輪郭の推定と描画順に依存する重なりの組み立てを分離。描画順の検証では推定済みの輪郭を再利用し、検証後に解放する。再検証が不要な場合は最初の組み立て後に解放する。
- 残差の検証に使う元画像・元の塗りの色差を必要な画素だけ計算し、候補間で再利用する。早期棄却後の未使用画素は計算しない。
- 独立した塗り候補の推定を既存のRayonプール内で並列化。結果は従来の順番に戻して比較し、同点時や貪欲な領域統合の採用順を保つ。
- 微小領域の統合では、近傍領域ごとの窓の再走査を一度の走査に集約。所有領域ごとの画素順、局所色・アルファの証拠、統合条件は保つ。
