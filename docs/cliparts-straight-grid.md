# Cliparts の細い区切り線の直線化

区切り線は黒い RGB と画素ごとに変化するアルファで保存されている。例えば縦線の y=200 では x=400,401 のアルファが 172,242。位置に応じて隣接する 2〜3 画素に濃さが分散し、中心位置も少しずつ移る。従来はこの分布を透明度別の面に分けて輪郭近似し、線の中心と幅を共有しなかった。

`alpha_lines::extract` は透明マスクを通常の領域に分ける前に、横断方向のアルファの合計と重心を測る。孤立した幅 4 画素以下の帯が 64 断面以上続き、中心が直線から 0.15 px 以内、濃さの合計が平均から 8% 以内にある場合だけ採用する。縦横両方を走査し、わずかな傾きも推定する。

採用した部分だけを元マスクから取り除き、一定幅の平行四辺形として追加する。最大の断面アルファを不透明度、濃さの合計を不透明度で割った値を幅とし、線を強制的に 1 px へ細くすることはしない。マスク内の一般的な面の継ぎ目補填ストロークを付けず、推定した幅を維持する。

空白や交差点は断面の連続性を切るため、隙間をまたいで結ばない。交差点は従来のマスク内に残す。曲線や幅の変わる帯も従来の輪郭処理に残る。

テストは、傾いた線の幅と濃さ、意図的な隙間、縦横の交差、曲線を対象にする。実画像の `src/test-data/cliparts-grid-alpha.png` は元画像 `(395, 0)` から `12 × 1200` のアルファ切り出しで、区切り線のアルファの 90% 以上を直線として取り出せることを検証する。
