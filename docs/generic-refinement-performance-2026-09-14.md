# 既存経路内の汎用的な性能改善

基準出力は `d77df52794659c0166eb72bc483cc32e49b1bb18` の `sample/output/*.svg` 全9枚。前段の[性能修正](latest-svg-performance-2026-09-14.md)を土台に、今回の変換処理の変更は `structural.rs` と `paint_order.rs` の2ファイルに限定した。[今回の差分](generic-refinement-performance-2026-09-14/changes.patch)には比較テストも含む。

## 連結成分上での残差線判定

従来は線の各連結成分について、画像全体の一時配列を初期化し、半径1の円盤膨張を全画素に実行していた。その結果を参照するのは同じ成分の画素だけだった。booster原寸5770×2058の追加計測では、構造線選別の約33秒中27.534秒が残差線処理だった。

半径1の円盤は中心と上下左右の5画素。問い合わせ位置が成分上にある場合、隣接する線画素は必ずその成分に属する。この条件を用い、同じ5画素を直接参照する。成分ごとの全画像配列と全画像膨張が不要になる。連結成分の欠損率、75%判定、小成分の除去、採否・列挙順は従来と同じ。計算量のうち「成分数×画像面積」の走査がなくなり、成分の画素数に比例する局所判定になる。

画像名や画素の色を特別扱いする分岐ではない。既存の残差線処理で常に成立する連結性と半径の条件を利用している。

## 複数帯域とクリップを持つSVGの塗り順序検証

高さが128画素を超え、幾何クリップを含むSVGでは、穴の検証で既に使っている描画部品の再利用を塗り順序の検証にも適用する。クリップのない場合、小さな画像、部品分割に対応しないSVGは従来の描画を使う。

再利用するレンダラーは、通常合成でフィルターのないグループについて子要素の描画範囲を調べ、描画対象がない帯域の処理を省く。独立レイヤーの再利用条件とメモリ制限も既存実装を使う。線幅、クリップ形状、座標原点、キャンバス、1倍・4倍のRGBA比較、許容誤差、誤差の集計順序は変えない。新しい変換パイプラインは設けていない。

描画検証だけを変更した試作では、6×6の塗り順序検証が43.749秒から26.998秒になったが、通し時間は291.131秒で、以前の285.151秒より遅かった。部分精細化の未変更段階も一様に遅く出ていたため、この段階別比較だけで全体の高速化を主張せず、保存済みの変更前実行ファイルとの交互比較を行う。
