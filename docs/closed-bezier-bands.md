# 閉じた輪郭と細い縁の簡略化

Wi-Fiの縁では、外形のベジェ曲線だけを減らしても、内側の色面と構造補正線が
細かな段差を描き直していた。以前のマスター数の確認だけでは、見えている線の
改善を確認できていなかった。

現在は外形・線の内側・すぐ内側の塗りを一緒に整え、最終SVGの描画で検証する。
画像名やWi-Fiの座標による分岐は設けていない。

## 閉じた外形

`geometry_bezier::fit_closed` は、既存の短い曲線との一致ではなく、原画像の
閉じた境界から最大8本の三次ベジェ曲線を推定する。円・楕円を優先し、
自由曲線では既存の幾何マスター数を減らせる場合に採用する。

- 約1ピクセル間隔で再標本化し、持続する角を固定する。滑らかな接続点の
  接線方向を共有し、画素単位の揺れには5点の局所平均を使う。
- 外形の残差は最大2.0、RMS 1.2処理ピクセル以内。原画像との双方向の標本距離は
  2.5ピクセル以内とし、向きの反転と標本化した輪郭の自己交差を拒否する。
  連続曲線に対する厳密な誤差証明ではない。
- 元の輪郭点数80～2,400、再標本化後64点以上を対象とする。角が4箇所を超える
  複雑な形や、面積／周長が3ピクセル未満の薄い形は対象外とする。
- 境界グラフの点を順序付きで対応付け、隣り合う色面が同じ曲線の部分区間を
  共有する。内部の色面との接続点も移動し、後段の局所処理による上書きを防ぐ。

採用した外形は `ClosedContour` に保持する。描画用に標本化した線から再び
外形を推定すると、処理領域によって再フィットが失敗するため、元のマスターを
そのまま縁の生成にも使う。

## 見えている縁

`outline::propose` は閉じた外形の法線方向に原画像を調べる。外側5ピクセルと
内側6ピクセルより暗い線の芯があり、輪郭の75%以上で支持される場合を対象とする。
単なる明暗の境界を新しい輪郭線へ変えてしまわないため、両側との明るさを比べる。

線幅は0.5～5.0処理ピクセルの観測から推定する。暗い芯から内側の色へ移る
明るさの35%の位置を測り、その37.5パーセンタイルを代表幅にする。
明るい縁取りまで暗い線へ含めすぎないための選択で、幅のp90−p10が
3.5ピクセルを超える候補は見送る。

1. 外形から法線方向に線幅を移動し、線の内側を作る。さらに1.25ピクセル
   内側に補修範囲の境界を作る。各内側境界は最大16本の三次ベジェ曲線、
   標本距離0.75ピクセル以内で近似し、自己交差なども検査する。
2. 線の色は原画像の暗い芯から、補修色は内側の原画像から採取する。
   細い線に混じるアンチエイリアスの色の揺れを7標本の中央値で抑える。
3. 色の変化が一つの塗りで表せなければ、必要な区間だけを分割する。
   最大8区間、各塗りは2～5ストップの線形・楕円放射グラデーションとする。
   線の色の平均／p95色差は5／10以内を要求する。補修色は境界の混色を含むため
   10／20以内とし、最終的な採否は後述の描画比較で決める。
4. 既存の色面と補正線は補修範囲より内側でクリップする。完全に隠れる色面・
   補正線・不要なグラデーション定義は出力しない。古い段差が線の内側から
   再び見えることを防ぐ。
5. 下塗りを置いてから縁と内部の色面を描く。隣接区間をわずかに重ね、外形で
   クリップすることで、アンチエイリアスの継ぎ目から白い隙間が出ることを防ぐ。

クリップ内の広い陰影は既存の塗りを使う。すべての陰影を一つの塗りに置き換える
処理ではないため、内部の色領域やハイライトの細かな分割は残る。

## 描画による採否と回帰テスト

候補がある場合だけ、置き換え前後の完成モデルを同じ背景で描画して原画像と比べる。
対象領域の平均DeltaE00の増加は0.75以内、縁付近の平均DeltaE00の増加は3.0以内とする。
完全一致を条件にせず、線を簡潔にするための小さな変化を許容する。
これは知覚的な無劣化を保証する値ではなく、最終画像の目視確認と併用する。

- `wifi-closed-contours.json` で外形の曲線数・順序付きグラフ対応・薄い形の拒否を確認する。
- 暗い縁と単なる明暗境界を区別し、大きな色変更や意図的な欠けを埋める描画を
  見送ることをテストする。
- `wifi-source.png` の通常変換を4倍描画し、中段の弧の見える内側境界を追跡する。
  境界位置の二階差分の平均絶対値を0.08処理ピクセル未満とする。
  同時に、元画像の青い前景に対する平均DeltaE00を4.0未満とする。
  マスター数が減っただけではこの描画テストを通過できない。

## サンプルの確認

全7入力を通常の変換で再生成する。Wi-Fiの比較は局所変換の結果ではなく、
再生成前後の全シートSVGから作る。

```sh
mise exec -- cargo build --release --locked --offline --features diagnostics
target/release/picvec sample/input/cliparts-6x6.png sample/output/cliparts-6x6.svg \
  --threads 4 --remove-chroma-key-background --verbose
mise exec -- cargo test --release --locked --offline --features diagnostics
```

[原画像・変更前・変更後](../sample/comparison/cliparts-6x6-wifi.png) は、
原画像の `(280, 2658, 310, 265)` に相当する範囲を白背景で2倍描画した比較。
原画像パネルでは緑の背景を白にしている。

[中段の縁の拡大比較](../sample/comparison/cliparts-6x6-wifi-detail.png) も、同じ全体SVGの4倍描画から切り出した。

| 測定対象 | 変更前 | 変更後 |
|---|---:|---:|
| シート全体のpath要素（定義内を含む） | 64,738 | 64,160 |
| シート全体の描画セグメント | 880,710 | 876,874 |
| シート全体のSVGバイト数 | 54,791,871 | 54,592,115 |
| Wi-Fi中段の内側境界の揺れ | 0.0931 px | 0.0541 px |
| Wi-Fiの青い前景の平均DeltaE00 | 2.6826 | 2.9951 |

中段の測定区間の揺れは約42%減った。色差は約0.31増えており、画素ごとの忠実度が
改善したとは主張しない。4つの縁が連続した簡潔な線になっていることと、陰影を
保持していることを、原寸・2倍・4倍の完成SVGで確認した。

シート全体では30個の縁を再構成し、不要になった色領域894個と補正線28本を除去した。
下塗り・色区間・クリップの追加を含めたpath要素の純減は578個。
高解像度補正は36枠すべて採用され、品質・境界・容量による見送りは0。
ベースの共有ループのフォールバック0、共有曲線のダウングレード3は変更前と同じ。

全テストは258件成功、4件は既存のignore指定。既存の
`stroke_model.rs` の `needless_range_loop` を除外したClippyは、通常機能・
`diagnostics` 機能の両方で成功した。
