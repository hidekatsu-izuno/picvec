# サボテン左下の点線の欠け

`sample/input/cliparts.png` の左下の楕円は元から細かな点線である。出力では透明部分に接する左端の数点がまとめて消えていた。キューブの角補正前の出力にも同じ欠けがある。

この部分では、黒い点が半透明のシルエットに接しており、塗り境界を近似すると黒の面積が透明マスクの外へ出てしまう。既存の透明境界の細線復元は明るい線に限定され、部分透明を含む画像も対象外だったため、欠けを補えなかった。

`recover_alpha_boundary` に暗い細線の復元を追加した。透明マスクと同じ曲線上で内向きの色断面を測り、透明度で重み付けして不可視の RGB を除外する。内側の塗りと十分なコントラストがある細い帯だけを採用する。暗い点線は最大 0.5 px の間隔で測り、幅の中央値による隙間埋めを行わない。明るい縁の既存の測定方法は維持する。

回帰フィクスチャ `src/test-data/cactus-circle.png` は元画像の `(455, 300)` から `100 × 85` の切り出し。欠けた左端の暗い点が復元されることを検証する。既存の円周の縁取りテストも暗い縁まで拡張し、連続した縁、意図的な隙間、縁取りのないシルエットを確認する。
