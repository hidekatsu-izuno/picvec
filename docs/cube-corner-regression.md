# Cliparts のキューブの角

元の `sample/input/cliparts.png` のシルエットには、左端と下端に小さな突起がある。直線の交点へ整える既存の角補正が、最終出力のすべての輪郭に適用されていなかった。

- 塗りの境界では、辺の中点から求めた直線とグリッド頂点との距離を同じ許容幅で比較していた。下端の距離は約 0.646 px で、0.6 px の上限により除外された。頂点と中点の表現差として半画素対角線まで許容する。
- 下端の除去面積も約 38 px² で従来の 32 px² を超えた。置換する直線に沿うラスタ境界の位置誤差を面積判定に加える。長い直線の支持、迂回長、交点位置、保護された接合点などの条件は維持する。
- 左端は塗り側で既に補正されていたが、透明境界のフィッターが元の突起を鋭い角として保護した。透明マスクとそこから作る縁取りが共用する `fit_alpha_contour` でも、角を保護する前に短い突起を補正する。補間済み座標はグリッドへ丸めない。

回帰テストは、実際の下端の境界点を収めた `src/test-data/cube-bottom-corner.txt` と、元画像のアルファを切り出した `src/test-data/cube-alpha.png` を使用する。後者は元画像の `(825, 0)` から `340 × 395` の範囲で、左端と下端の両方を検証する。既存の小さな島、矩形の角、円形の透明境界のテストも維持する。
