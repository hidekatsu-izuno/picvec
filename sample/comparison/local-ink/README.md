# 小さい文字・細線の局所修復

前回の文字保護処理（`e14f1d9`）を置き換えました。booster-layoutの文字のつぶれは大きく改善し、catwhaleの改善は小幅です。文字と図面の線が接続した箇所や、背景に埋もれた薄い文字には崩れが残ります。速度と一部の画素指標には悪化があります。

## 変更内容

通常のベクトル化には加工していない元画像を渡します。完成したSVGに対し、元解像度で抽出した細い形状の輪郭を局所的に当てはめ、元画像との誤差が減る範囲だけ置き換えます。文字の穴、隣接する印、境界、8×8画素ごとの誤差も確認します。隣接範囲の接続を改善できるよう最大2回検証します。

対象は不透明画像の、局所的に背景色と前景色の2色で説明できる細い形状です。文字認識やフォントへの置換はしません。完全に覆われる既存形状は除去し、マスクや透明な隠蔽図形は生成しません。透明画像は通常処理を使います。

## 文字領域の比較

`original` は文字保護導入前の `c659d51`、`previous` は前回の `e14f1d9`、`revised` は今回の出力です。以下の矢印は **previous → revised** です。

| サンプル | 元画像OCRとの不一致率 ↓ | インク領域IoU ↑ | 領域RGB MAE ↓ |
| --- | ---: | ---: | ---: |
| catwhale | 17.2% → 16.3% | 0.8472 → 0.8497 | 6.842 → 6.958 |
| booster-layout | 34.3% → 16.3% | 0.7411 → 0.8791 | 25.329 → 15.129 |

ocrs-cjkは[独立した評価ツール](../../../scripts/ocr_eval/README.md)でのみ使用します。リビジョンは `2f72f76ac2152ee1112ee6b6e36048bab069f391`、モデルはPP-OCRv5です。検出は元画像だけで行い、完成したSVG全体を元サイズで描画して同じ固定領域を比較しました。評価用SVGと配布SVGのXML内容の一致も確認しました。

catwhaleは41検出領域、うち非空の参照文字列35件・203文字、booster-layoutは54領域、うち33件・306文字です。不一致の編集数はそれぞれ35→33、105→50です。未認識文字も削除として数えます。画素指標には空の参照文字列の領域も含みます。参照は誤りを含む元画像のOCR結果であり、人手の正解文字列に対する認識精度ではありません。

## 全体への影響

全10件のSVGのハッシュ・構造を確認しました。今回5件を再生成し、他5件は前回生成した出力を保持しています。originalと比較すると、静物画・Wikipediaロゴ・car・viewport2・boy_and_turtle・cliparts・cliparts-6x6の7件はバイト単位で一致します。Wikipediaの歪んだ文字は修復していません。静物画は前回の処理による網目の変更を解消し、originalに戻りました。

originalから変わったのはbooster-layout、catwhale、viewport1です。元サイズでのRGBA比較で、採用した修復矩形の外側の変化は全件0画素でした。修復内の全画素で改善するという意味ではありません。64画素タイル単位では一部に誤差増加があります。

| サンプル | 全体・白背景RGB MAE ↓ | 全体・白背景SSIM ↑ |
| --- | ---: | ---: |
| booster-layout | 4.204 → 3.824 | 0.94782 → 0.95193 |
| catwhale | 3.656 → 3.635 | 0.93680 → 0.93676 |
| 静物画 | 12.075 → 12.116 | 0.78317 → 0.78270 |
| viewport1 | 12.660 → 12.637 | 0.72456 → 0.72330 |

catwhaleは文字領域のRGB誤差が微増し、全体の黒背景RGB誤差も3.672→3.691に増えました。全体のアルファ誤差も0.079→0.124です。静物画の元の形状への復帰も平均指標の改善とは一致しません。全指標での改善とは判定していません。黒背景・アルファ・局所差分を含む詳細は[results.json](results.json)に保存しています。
